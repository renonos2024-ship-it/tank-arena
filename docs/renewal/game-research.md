# 宵まちメダル横丁：実在ゲーム構造研究（Phase 0）

調査日：2026-10-14。対象：指定6シリーズ＋縁日系2タイトル。

## 結論

最初に移植すべきものは大量払い出しの見た目ではなく、**入力が盤面を変え、変化が読め、次の行動を選べる循環**である。プッシャーは押す・積む・崩れる、射的は命中点と姿勢変化、金魚は差し込み・荷重・持ち上げの因果を優先する。JP・図鑑・共通祭りはこの循環を拡張する層として追加する。

公式説明で操作できると書かれていても、その入力が実機の当選確率をどの程度変えるかは通常非公開である。本作では技術介入を隠れた当選補正で再現せず、接触・位置・時間・選択の検証可能な状態遷移として実装する。

## 調査の範囲と確度

- **O（公式確認）**：メーカーの本文・画像代替テキストで確認。実機を自分で計測した事実ではない。
- **P（プレイヤー報告）**：攻略記事・個人記録の主張。仕様の保証、内部確率、統計的検証ではない。
- **H（設計仮説）**：本作への独自提案。参考作品に実装されているとの意味ではない。
- 指定KONAMIの3ページは旧作の製品説明。下記の個数・手順はそのページの版に限り、現在の全シリーズ共通仕様とはしない。
- 動画URLと公式映像案内は発見したが、本調査環境では映像・音声の再生観察、フレーム検証、実時間計測をしていない。YouTubeの一部は取得エラー、一部は説明のみ。**動画を視聴済みとは扱わない**。
- 成功までの秒数、技術別成功率、還元率は全タイトル未計測。以下のテンポ記述は「操作／抽選の単位」であり秒数ではない。
- 二次資料にある「内部」「回収期」「放出期」「必勝」などは独立検証されておらず採用しない。掲載日・機種版・店舗設定・編集済み成功集による偏りにも注意する。
- 筐体・名称・キャラクター・UI・音源・固有演出は複製せず、構造の抽象化だけに用いる。

## 1. バベルのメダルタワー／W！

公式根拠：[B1](https://www.sega.jp/arcade/detail/babeltower/)、[B2](https://www.sega.jp/arcade/detail/babeltower-w/)。二次根拠：[B3](https://mabo-medalgame.com/babeltower-how-to-play/)、[B4](https://game.watch.impress.co.jp/docs/kikaku/1514226.html)（B4はGAPOLI版で実機と区別）。

O：タワーを建ててフィールド上で倒すプッシャー。Wはタワーを段階に分け、ガイドで前進を助ける。オーブからサテライト抽選を経由してJPへ進む。P：中央への投入、盤面・オーブ位置の確認が攻略として語られる。ただし最適性は未検証。

| 分析項目 | 観察された仕組み → 面白さの仮説 → 本作の実装 |
|---|---|
| 1 操作 | O メダル投入で盤面を押す → H 自分の1枚が後続の移動を生む因果が見える → 投入口を相対操作、位置と押し板位相を記録 |
| 2 技術介入 | P 狙う盤面・投入場所を選ぶ → H 押す方向の見立てを試せる → 同一初期盤面・同一投入数で中央／端／位相を比較 |
| 3 快感 | O 高いタワーが崩れる → H 小さな変形の蓄積と大規模崩壊の差が成果を実感させる → 剛体傾き・接触インパルスにSEと破片を同期 |
| 4 イベント導線 | O オーブ→サテライト→JP → H 次の目標までの距離が分かる → 独自の祭り印収集→物理球の小抽選→建設チャレンジ |
| 5 小成果の単位 | O 通常の押し出しとタワー建設は別段階。秒数未測定 → H 大崩壊前にも微小前進が必要 → コイン移動距離・傾斜・手前落下を別々に記録 |
| 6 JPで変わること | O 大量のメダルが盤面上のタワーになる → H 報酬が次の攻略対象になる → 建設枚数と実際の手取りを別表示・別台帳 |
| 7 反復性 | O 同じ投入でも盤面が残る → H 自分が作った未完の配置に戦略の続きが生じる → 位置・回転・速度・押し板位相を保存 |
| 8 応用 | O ガイドでタワーの進路を支援 → H 支持面が予測可能なら理不尽さが減る → 安定した初期配置、側方ロスの可視化、再開時の物理ウォームアップ |

**設計上の注意**：盤面に供給された100枚を100枚の手取りと数えてはいけない。初期盤面、プレイヤー投入、イベント供給、手前回収、側面ロス、盤面残数を別々に保存・集計する。実時間のモーニング／イブニングサービスや現金継続は移植しない。

| 6 JP変化 | O 専用の大量払い出し演出 → H 規模に比例した演出が特別感になる → 音の層を追加しつつ操作領域を遮らない |
| 7 反復性 | O 異なる抽選方式と収集記録 → H 同じ収支以外の目的が選べる → 通常盤面攻略／印収集／記録更新を並立 |
| 8 応用 | O 複数抽選の体系 → H 1画面に全部見せるより局面を切る方が理解しやすい → まず1抽選だけ完成、複数系統はPhase 2以降 |

**採用しないもの**：実機のリーチ演出から内部当選率を推定すること、抽選結果確定後に球を当たり／外れへ誘導すること。

## 4. カラコロッタシリーズ

公式根拠：[C1：指定ページの初代説明](https://www.konami.com/arcadegames/products/site/am_colorcolotta/info.html)、[C2：トロピカルリゾート公式](https://p.eagate.573.jp/game/lotta/cc7/)（シリーズ継続確認用、初代の個数を最新作へ流用しない）。二次根拠：[C3](https://mabo-medalgame.com/colorcolotta-how-to-play/)。

| 3 快感 | O 1球ずつ継続・終了が決まる → H 毎球で意味が変わる → 物理入球後のみ判定、カメラがポケットを隠さない |
| 4 イベント導線 | O 通常→蓄積→中間→JP → H 1ラウンドの敗北と長期の進捗は両立 → 失敗を勝利演出せず、保存された収集進捗は別欄へ |

| 6 JP変化 | O 特定ポケットへの複数球チャレンジ → H 同じ装置でも成功条件を変えると意味が変わる → 独自配置のJP装置と球数を明示 |
| 7 反復性 | O 連鎖／ライン／色一致の異なるルール → H リスクの好みと戦略を選べる → 低分散・中分散の2モードから開始、収支履歴を表示 |

**家庭用での差別化**：終了後に即再挑戦可能、全進捗保存、手動ポーズ。期間限定施策や参加しない日の不利益は採用しない。

| 6 ボーナス変化 | O 協力／特別ステージ → H 魚の密度や組合せが変わると狙い方も変わる → 大量発生では軽量魚を群れにし、合計荷重で駆け引き |

| 8 応用 | O 水平の共有盤面 → H 全体の配置を理解しやすい → 1枚のポイだけ描画、魚／ポイの縮尺を一致 |

**検証課題**：重なって見えるのに捕れない場合は、確率の問題と決めつける前に深さ・紙面支持・魚の逃避を画面で説明できるか確認。K2の投入枚数と「放出期」の関連は未検証のため採用しない。

## 8. もしかして？おばけの射的屋（追加調査）

公式根拠：[O1：エンハート](https://enheart.co.jp/medal/おばけの射的屋/)、[O2：家庭用版の日本コロムビア公式発表](https://prtimes.jp/main/html/rd/p/000004905.000019470.html)。二次根拠：[O3](https://medalgame.net/obake-no-shatekiya)。O2の家庭用独自要素を実機へ遡及しない。

O：メーカーは物理演算による射的を明記。家庭用紹介では狙って景品を落とす局面と次々に敵を倒す局面を区別し、昇降・回転する棚を説明。P：景品の反応を観察し、後半へ資源を残す攻略がある。内部の命中・転倒係数は非公開。

| 分析項目 | 仕組み → 仮説 → 実装 |
|---|---|
| 1 操作 | O 景品を狙って撃つ → H 入力と接触の因果を追いやすい → 相対照準を保存、別指の発射で照準を動かさない |
| 2 技術介入 | O 物理演算、P 景品の反応観察 → H 弱点・重心・接地点が読める → 命中位置からトルク計算、材質別の揺れ。クリティカル範囲は同条件で公開 |
| 3 快感 | O 景品が倒れる／敵を撃退 → H 通常命中と獲得の違いが分かる → 小音＋局所揺れ、確保時は別音。HP数値は出さない |
| 4 イベント導線 | O 通常射的から敵・ボス局面 → H じっくり狙う技能と素早い判断を使い分ける → 黄金標的→連続命中課題→独自ボスの3局面 |
| 5 小成果の単位 | O 1命中と景品獲得。秒数未測定 → H 獲得前にも正しい狙いが伝わる → 通常命中の小ダメージを維持し、姿勢変化を明示 |
| 6 ボーナス変化 | O ボス撃破と大きな報酬 → H 習得した技能の総合試験になる → 予告付き反転・弱点回転・遮蔽タイミングの組合せ |
| 7 反復性 | O 異なる棚の動き、家庭用収集要素 → H 違う軌道・配置に学習を転用できる → 完全ランダムでなく有限の動作パターンを合成 |
| 8 応用 | O 静かな狙いとラッシュの対比 → H 同じ入力でも判断速度が変化 → 通常は精密さ、ラッシュは優先順位と弾種選択を問う |

**独自性**：幽霊・景品化け・既存ボス・UIの再現ではなく、木・陶器・紙細工を使った宵まち独自の祭具と動作に置換する。

## 検証計画と未達事項

本研究は実装根拠の整理であり、面白さ・115%還元率・60fpsを証明するものではない。以下は本研究担当では実施していない。コード監査・経済試行・実装検証の結果は、それぞれの別レポートを正とする。

1. 各タイトルの連続映像観察と時間計測。
2. 本作の初心者・標準・熟練のユーザーテスト。属性による密かな判定変更はしない。
3. 10万回以上の経済試行、物理盤面を含む長時間の収支検証。
4. iPhone Safari実機での同時タッチ・音声・30分継続計測。

操作の納得感、初回からの技能改善、達成感、もう一度別の方法を試したいか、失敗理由を説明できるか、ストレスを評価する。プレイ時間が伸びてもこれらが悪化した場合は成功としない。失敗後に進捗が残る設計は採用可能だが、負けを勝利として演出せず、いつでも保存して終われるようにする。
